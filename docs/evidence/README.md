# Evidence protocol

M0 development evidence is under ignored artifacts/, separate from candidate source. Local checkpoint commits identify source; dirtyDigest/sourceDigest additionally identify exact local files when manager records or implementation remain uncommitted. candidate.json enumerates file and built-artifact hashes; candidate-check.mjs recomputes actual identity. Release requires a real clean source commit and all applicable acceptance evidence.

Unit and browser runners capture actual identity before execution, reject changes during execution, and attach actual runner outcomes. unit-evidence.mjs archives earlier reports/evidence and invalidates latest-success state before even the build precheck so a launch failure cannot borrow older passes. These attestations are development proof, not accepted per-obligation release evidence. req:check checks structure; release:check deliberately fails absent clean candidate/approved inventory/evidence. Gate functions are tested with independent mappings, but approved evidence-kind/device coverage and production report ingestion remain incomplete.

Reproduce with pinned Node/pnpm: build; test:unit; req:check; fixture:check; proof:browser against pnpm preview. Independent PDF inspection: Python with pdfplumber runs scripts/pdf-inspect.py; Poppler pdftoppm renders all pages. Keep failed attempts, initial errors and unavailable checks. Browser Chromium is a desktop proxy; no real tablet/mobile result is inferred.

The PDF font is unmodified DejaVuSans from the Codex bundled LibreOffice runtime. Redistribution notices are in apps/web/public/fonts/LICENSE.txt. The exported fixture rows/prices/quantities are explicitly synthetic. Font/source hashes appear in candidate.json. Third-party package versions/licenses/notices are in dependency-inventory.json; audit output is dependency-audit.json. Audit reports zero known advisories at execution time; maintenance and issue review remain pending and cannot be inferred from that count.
