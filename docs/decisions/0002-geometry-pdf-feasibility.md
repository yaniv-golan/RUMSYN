# ADR 0002 - Geometry and PDF feasibility candidates

2026-10-08. Pending manager review; no complete selection approval. R005-R008/R016/R021/R034-R036/R038/R041/R042.

Installed Manifold 3.5.4 (Apache-2.0), polygon-clipping 0.15.7 (MIT), jsPDF 4.2.1 (MIT). Manifold proves bounded solids, offsets and extrusion; polygon-clipping proves narrow planar subtraction. Retain domain line/arc/face IDs independently; the current face mapping proof is domain-level, not renderer triangle assignment. Initial numeric/resource budgets are frozen in source before execution. Curved annulus is a proxy; curved joint topology still needs focused qualification. Frame geometry and detailed intersection classification are partial. G06 desktop load/compute runs, tablet/memory growth/cancellation not_run.

jsPDF initially failed P02/P04 mixed-direction text (English/article/price/Hebrew reversal) and P03 A4 clipping. Failed outputs/reports remain in artifacts/browser/attempt-1. Corrected logical-input/visual-output bidi options preserve English tokens; A4 landscape retains 1:20 scale and keeps the 400cm plan within bounds. A3 stays portrait. Embedded DejaVuSans is copied unmodified from the bundled runtime; its Bitstream/Arev redistribution notices accompany it. Independent pdfplumber reads coordinates/text/links and all-page bounds; Poppler renders output for visual review. Scale target is a 100cm line represented by exactly 50mm at 1:20. Physical actual-size print and mobile independent viewers are not_run. Full Hebrew consumer acceptance remains pending.

The M0 PDF harness uses labeled synthetic rows, quantities and prices, never claims IKEA coverage. It tests 70 linked rows, missing prices, long labels, repeated headers and page breaks. No dependency is selected solely from a screenshot. Production exporter remains subject to full P01-P05 qualification.

Second independent-reader defect: pypdf dropped short Hebrew labels in mixed-direction single text calls despite correct glyph appearance. Failed attempt-2 files remain preserved. Separate Hebrew/Latin directional text runs now preserve the room label and all 63 short product labels in pypdf extraction; long Hebrew rows wrap independently above Latin article/price lines. This is a bounded formatting strategy, not full arbitrary bidi layout qualification. Independent assertions now require Hebrew extraction as well as English identifiers, prices, links, headers and bounds.
